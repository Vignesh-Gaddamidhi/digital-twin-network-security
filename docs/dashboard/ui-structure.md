# UI Structure & Viewport Layout
- **Header**: System status, environment mode, simulation state, active analyst, and WebSocket health indicator.
- **Top KPI Bar**: Four summary cards for Devices, Threats, Risk, and Attacks.
- **Center Canvas**: Interactive directed topology canvas with subnet zone bounding boxes and drill-down side-drawers.
- **Lower Three-Column Analytics Grid**:
  1. Traffic throughput sparklines and protocol distribution.
  2. Chronological threat timeline with detection source attribution.
  3. ML inference, dual-horizon probabilities, and SHAP waterfall chart.
