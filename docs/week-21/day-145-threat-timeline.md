# Day 145: Threat Timeline & Real-Time Event Stream

## 1. Unified Event Taxonomy
The timeline unifies multi-stage telemetry into an auditable event ledger:
- `SECURITY_EVENT`: General telemetry baseline or protocol deviation.
- `IDS_ALERT`: Signature matches generated by Suricata/Zeek ingestors.
- `ML_PREDICTION`: Probabilistic threats classified by the random forest or time-series engines.
- `RISK_CHANGE`: State transitions emitted by `RiskStateEngine` (e.g., `MEDIUM -> HIGH`).
- `ATTACK_PATH_EVENT`: Lateral movement trajectories discovered by `PathDiscoveryEngine`.
- `SIMULATION_EVENT`: Controlled lifecycle markers (`SCENARIO_STARTED`, `HOST_ISOLATED`).
