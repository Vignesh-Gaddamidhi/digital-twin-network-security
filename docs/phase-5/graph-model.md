# Phase 5: Digital Twin Graph Model G = (V, E)
Mathematical graph representation implemented via NetworkX:
- Vertices ($V$): Devices annotated with type, zone, operational health, and risk score.
- Edges ($E$): Directed and bidirectional connections annotated with protocol, status, and latency weight.
- Enables graph queries: successors, predecessors, degree counts, and subgraph slicing.
