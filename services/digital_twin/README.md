# Digital Twin Core Engine (v0.1)

Contains the canonical registries and graph models:
- `core/devices`: Device CRUD and identity management.
- `core/connections`: Layer 1-4 connection lifecycle management.
- `core/topology`: NetworkX directed graph analysis and shortest path finding.
- `core/state`: Dual-track operational/security FSM and immutable audit trails.
- `core/vulnerabilities`: CVE tracking, lifecycle management, and exposure calculation.
